# OnDuty (MVP · Python 버전)

당직사관 · 일직사관 · 비상대기 · 차출 근무표를 순번 규칙에 따라 자동 편성하고, 변동을 즉시 반영하며, 근무자 알림을 남기는 웹 앱입니다. 요구사항은 `PRD-근무순번도우미.md`를 따릅니다.

- **추가 설치 없음**: Python 3.9 이상만 있으면 됩니다(표준 라이브러리만 사용, 외부 CDN 없음 → 내부망에서 그대로 동작).
- 데이터는 같은 폴더의 `data.db`(SQLite) 파일에 저장됩니다.

## 실행 방법

1. 이 폴더에서 **`run.bat`을 더블클릭**합니다.
   - 또는 터미널에서 `python server.py`
2. 브라우저가 자동으로 열립니다. 안 열리면 주소창에 **http://localhost:8000** 을 입력합니다.
3. 종료: 실행 창에서 `Ctrl + C` 또는 창 닫기.

처음 실행하면 시연용 **가상 데이터**(간부 1명 + 근무자 40명, 4개 부서, 이번 달 확정 근무표, 공휴일 2개, 휴가 1건)가 자동으로 만들어집니다. 처음 상태로 되돌리려면 서버를 끄고 `data.db`를 지운 뒤 다시 실행하세요.

## 시연 순서 (완료 기준 D1~D8)

| 장면 | 하는 방법 |
|---|---|
| A. 월말 편성 (D1, D2, D8) | `대위 편성담당`으로 로그인 → **편성 관리 → 자동 편성·확정** → 다음 달 [자동 편성] → 검증 결과·인원별 평일/주말 횟수 확인 → [달력에서 보기·수정]에서 칸을 눌러 수동 수정 → [확정] |
| B. 중간 변동 (D3) | **편성 관리 → 휴가·출장**에서 확정된 날짜의 근무자를 휴가 등록 → 그 날짜만 바뀐 결과 표시, **순번·보충 대기열**에 빠진 사람이 오름, **변경 기록**에 남음. 다음 달을 편성하면 그 사람이 복귀 후 첫 근무일에 먼저 배정됨 |
| C. 내 근무·교대 (D4, D5) | 근무자로 로그인 → 첫 화면에 내 다음 근무 → 월간 근무표에서 노란 내 칸 클릭 → 대상자(같은 근무 종류만) 선택 → [교대 요청]. 로그아웃 후 상대방으로 로그인 → [수락] → 표 즉시 반영, 두 사람과 간부에게 알림 |
| D. 전날 알림 (D7) | 서버가 매일 17:00에 다음 날 근무자 알림을 자동 생성. **알림 관리 → [지금 바로 실행 (시연)]**으로 즉시 확인 가능 |
| E. 차출 (D6) | **편성 관리 → 차출 뽑기**에 인원 수 입력 → 다음 순번부터 선발, 기록·알림 생성 |

알림 실패·재발송 시연: 가상 데이터 중 2명은 휴대폰 번호가 비어 있어 알림톡이 **실패**로 기록됩니다. 인원 관리에서 번호를 넣고 알림 관리에서 [재발송]하면 성공으로 바뀝니다.

## 설정 (`config.json`)

| 항목 | 설명 |
|---|---|
| `host`, `port` | 기본 `127.0.0.1:8000`. 내부망의 다른 PC에서 접속하게 하려면 `host`를 `"0.0.0.0"`으로 |
| `daily_notify_time` | 전날 알림 시각 (기본 `"17:00"`) |
| `auth.dev_login` | 개발·시연용 임시 로그인. **운영 전환 시 `false`** |
| `auth.sso` | 인트라넷 계정 연동(X1). 규격 수신 후 `app/auth.py`의 `IntranetSSO` 구현 |
| `mail` | 군 메일 SMTP(X2). `enabled: true`와 서버·계정을 넣으면 실제 발송 |
| `alimtalk` | 알림톡 체계(X3). 규격에 맞춰 `app/notifier.py`의 `_alimtalk` 어댑터 수정 |

메일·알림톡이 `enabled: false`이면 **테스트 모드**로, 실제 발송 없이 알림 기록에만 남깁니다(상단 노란 띠로 표시).

## 편성 규칙 구현 요약

- **R1** 평일 / 주말·공휴일 순번을 근무 종류별(비상대기는 부서별)로 따로 돌림
- **R2·R3** 휴가·출장자는 건너뛰고 보충 대기열에 올림 → 다음에 배정 가능한 첫 근무일에 대기열을 먼저 확인
- **R4** 같은 날 두 근무 금지 · **R5** 같은 근무 연속 이틀 금지(설정에서 끌 수 있음). 이 때문에 건너뛴 사람도 보충 대기열로
- **R6** 확정 뒤 휴가·출장 등록 시 해당 날짜 칸만 다시 편성
- **R7** 재편성·교대·수동 수정·설정 변경은 모두 변경 기록에, 연락처 열람은 별도 개인정보 접근 기록에 남음
- 초안 상태에서는 [다시 자동 편성]해도 순번이 이중으로 넘어가지 않도록 편성 직전 순번 상태를 저장해 두고 되돌림

## 폴더 구조

```
server.py          웹 서버 + 17:00 스케줄러
config.json        연동·포트 설정
app/engine.py      편성 엔진(순번, 보충 대기열, 규칙, 교대, 차출, 알림 생성)
app/api.py         API
app/notifier.py    군 메일·알림톡 어댑터, 알림 문구
app/auth.py        로그인 모듈(임시 로그인 / SSO 교체 가능)
app/db.py          SQLite 스키마
app/seed.py        시연용 가상 데이터
static/            화면(HTML·CSS·JS)
```
